# mh2-affinity
Removes forced single core affinity from PC version of Manhunt 2.

# Installation
1. Get [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases) (Win32 d3d9.dll)
2. Copy the **d3d9.dll** next to **Manhunt2.exe**
3. Download the mod from [Releases](https://github.com/Blackbird88/mh2-affinity/releases)
4. Copy the **mh2_affinity.asi** next to **Manhunt2.exe**
5. Launch the game! (You can check in Task Manager if it's using all the cores)
